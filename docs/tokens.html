Rules

Every item from the token review in docs/PLAN.md is done. These are the rules that keep it that way.

Roles, not palette

Components colour things with --color-* roles. Palette names are for brand decoration only.

Headings set globally

All h1 to h6 use --font-display from base.css. Components set size and weight only.

Text is capped

Paragraphs, list items, quotes and captions stop at --measure. Centred blocks use the centered mixin.

Fallbacks are metric-matched

Each web font has a scaled Georgia or Arial fallback, so text doesn't jump when fonts load.

Still open: breakpoints

Media queries are desktop-first (max-width). New components should use min-width. (T13)
